Module last_target_pos

Module author: Gian Marco Balia

This module implements a service node that, when called, returns the coordinates of the last target sent by the user.

Service:

target_pos

first_part.scripts.last_target_pos.main()[source]

Initializes the ROS node and service target_pos.

The service returns the last target position sent by the user when called.

first_part.scripts.last_target_pos.pos_target(req: first_part.srv.TargetPos) → first_part.srv.TargetPosResponse[source]

Service callback function to return the last target position.

Parameters:

req (TargetPos) – Empty request sent by the user.

Returns:

Response containing the last target position.

Return type:

TargetPosResponse

The target position is retrieved using two float parameters defined in the launch file assignment1.launch in the package assignment_2_2024.
